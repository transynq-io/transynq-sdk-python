# Code of conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: everyone taking part in this project (issues, pull requests, discussions, reviews) is expected to be respectful and
welcoming, to accept constructive criticism, to focus on what is best for the community, and to show empathy. Harassment,
insults, personal or political attacks, publishing others' private information and other conduct that could reasonably be
considered inappropriate are not tolerated.

## Enforcement

Report unacceptable behaviour to **CONDUCT-CONTACT-PLACEHOLDER** (the maintainers replace this with a monitored address before
the repository is opened to contributions). Reports are reviewed promptly and in confidence. The maintainers apply the
enforcement guidelines of the Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban).
