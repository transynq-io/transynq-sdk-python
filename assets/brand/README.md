# Transynq brand assets

| File | Use |
|---|---|
| `transynq-logo-light.png` | logo with navy text, transparent background: for light backgrounds |
| `transynq-logo-dark.png` | logo with white text, transparent background: for dark backgrounds |
| `transynq-icon-{16,32,48,64,128,256,512}.png` | app tile icon (transparent corners); `transynq-icon-128.png` is the package icon |
| `favicon.ico` | favicon of the generated documentation sites |
| `transynq-social-preview.png` | 1280x640 image to upload in the repository's **Settings > General > Social preview** (GitHub does not read it from files) |

Brand colours: primary `#2563EB`, secondary `#06B6D4`, accent `#8B5CF6`, success `#10B981`, warning `#F59E0B`, error `#EF4444`;
near-black `#0B1220`, dark grey `#1F2937`, grey `#6B7280`, light grey `#E5E7EB`, off-white `#F8FAFC`, white `#FFFFFF`.
Typefaces: Inter (headings and body), JetBrains Mono (code). Tagline: "Intelligent Transport Operations".
